Stump has a flexible layout system that allows for basic customization to the layout of the app, with some improvements planned down the road.

## Sidebar

The sidebar is the primary navigation for the web app. It is minimally configurable (e.g., to rearrange the items within it). On smaller screens (e.g. mobile), the sidebar is replaced by a burger menu which opens the navigation in a sheet overlay.

### Sidebar Style

You can choose how the sidebar is rendered using the `Sidebar Style` option in the appearance settings:

- **Normal**: The default, sidebar look
- **Floating**: The sidebar floats slightly detached from the edge of the app
- **Inset**: The sidebar is inset within the app's background

### Collapse Behavior

You can control how the sidebar collapses using the `Collapse Behavior` option in the appearance settings:

- **Show Icons**: Collapsing the sidebar reduces it vertical stack of icons
- **Fully Hide**: Collapsing the sidebar hides it entirely until you need it again

## Arrangement

You are able to customize the order of the navigation items to your liking. You can also hide / show items as you see fit.

### Customization

To customize the layout of the app:

<Steps>

<Step>

#### Navigate to appearance settings

You can access the settings page by clicking on the cog icon at the bottom of the sidebar, then clicking on the appearance tab

</Step>

<Step>

#### Open the arrangement editor

Find the section named `Navigation arrangement` and click the `Edit` button. This will open an editor where you can drag and drop the items to rearrange them, and toggle the visibility of items by clicking on the eye icon

</Step>

<Step>

#### Customize to your liking

To make any changes, you need to click the lock icon to unlock the arrangement. Once you are done, click the lock-open icon again to lock the arrangement. Changes are saved automatically as you make them, so you don't need to worry about losing your changes if you forget to lock the arrangement.

</Step>

</Steps>

## Home Page Sections

In appearance settings, find **Home page** and select **Edit** next to **Home sections**.
You can show or hide Continue reading, Your next read, Recently added books, and
Recently added series. Use the eye button to show or hide a section, and drag its
label to change its position. To reorder with the keyboard, focus a section label,
press Space to pick it up, use the arrow keys to move it, and press Space again to drop it.

Use the **Reset** and **Save** buttons at the top of the editor.
Select **Save** to apply your changes. These preferences are stored on the server
for your account and are restored when you return to the web app. Closing the
editor without saving discards your changes. **Reset**, followed by **Save**,
restores all four sections in their original order.

You can hide every section. The home page will then show a link back to appearance
settings so you can enable them again.
