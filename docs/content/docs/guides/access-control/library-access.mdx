A user must be explicitly granted access to see content in a library. By default, only the user who created a library will be automatically granted access to it.

## Configure Access

<Callout title="Permission required">
	This functionality is gated behind the `MANAGE_LIBRARY` and `READ_USERS` user permissions. To
	learn more about permissions, see the [permissions](/docs/guides/access-control/permissions)
	guide. Additionally, you must have access to the library you are trying to manage.
</Callout>

<Steps>

<Step>
### Navigate to the library settings

Navigate to the library you want to exclude the user from and click on the `Settings` tab.

</Step>

<Step>
### Select `Access Control` in the sidebar

The `Authorize users` section is located towards the bottom of the settings page. It contains a multi-select dropdown that allows you to select the users you want to have access to the library.

</Step>

<Step>
### Select the user(s) to grant access

UUse the multi-select dropdown to select the user you want to to grant access to the library. You can select multiple users if you want to grant access to more than one user.

</Step>

<Step>
### Save your changes

Autosave is enabled, so any changes should take effect immediately.

</Step>

</Steps>

## OIDC-Managed Libraries

You can configure a library to be OIDC-managed by specifying the groups which are allowed to access the library. This assumes that you have properly configured OIDC for your Stump instance. For more information, see the [OIDC](/docs/guides/access-control/oidc) guide.
